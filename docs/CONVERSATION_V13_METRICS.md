# 对话智能层 v1.3 结构化评测（零模型/零数据库）

- 说明：本表是**纯规则决策层**的可复现结构指标，不是真人自然度；自然度仍待人评。
- 覆盖：真实纠正/正常追加、分享不追问、缺关键事实只问一个、已知信息不重复索取、临时/长期约束落实、自然语言撤销。

## 指标
| 指标 | 结果 | 定义 |
|---|---|---|
| repair_success | 100% | 真纠正后回应动作确实改为修复且承接正确期待 |
| repair_false_positive | 0 | 正常追问被误判为纠正的次数（越低越好，理想 0） |
| unnecessary_question_rate | 0% | 分享轮强制追问的比例（越低越好） |
| essential_clarification_recall | 100% | 确需澄清时确实只问一个 |
| repeat_question_rate | 0% | 已知信息仍再次索取的比例（越低越好） |
| constraint_enforcement | 100% | 临时约束仅本轮、长期约束持续遵守 |
| undo_success_rate | 100% | 自然语言撤销解析正确且确为可执行逆操作 |

## 分用例
| 用例 | 分类 | 结果 | 断言 |
|---|---|---|---|
| r1 | 真实纠正 | 通过 | ✓ |
| r2 | 正常追加 | 通过 | ✓ |
| q1 | 分享 | 通过 | ✓ |
| q2 | 缺关键事实 | 通过 | ✓ |
| q3 | 关键信息已给 | 通过 | ✓ |
| q4 | 已问未答 | 通过 | ✓ |
| c1 | 临时约束 | 通过 | ✓ ✓ |
| c2 | 长期约束 | 通过 | ✓ |
| u1 | 自然语言撤销 | 通过 | ✓ |

已知限制：规则覆盖有限（槽位任务、纠正句式），不代表任意表达都能正确识别；真实提升仍需人评与真模型 A/B。
复现：`npx tsx scripts/conversation-eval/structural.ts`（不调用模型、不读数据库）
