# AI WebChat Windows 启动器

在项目根目录双击 `AI WebChat.exe`。启动器会在后台运行生产版网站，等本地数据库和网站就绪后打开默认浏览器。再次双击会复用已运行的服务。关闭浏览器后，后端仍在后台运行。

启动器与项目目录一起使用。它需要已安装的 Node.js、项目依赖和已配置的 PostgreSQL 服务，并读取项目原有的 `.env`。它使用本机地址 `http://127.0.0.1:3000`，供这台电脑访问。

维护者更新代码后，在项目根目录运行 `pwsh -File scripts/windows/build.ps1`，重新构建网站、应用数据库迁移并生成启动器。若旧服务仍在运行，先结束该项目的后端进程，再双击启动器加载新版。启动诊断保存在 `dist/windows/backend.log`。
